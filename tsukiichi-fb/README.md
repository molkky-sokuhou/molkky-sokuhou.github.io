  - 開いている回の書き換えは、毎回 rev が変わらないと断る（版12以前の端末からの得点訂正・チーム変更は断られる）。受付を消すときも同じまとめ書きで rev を変える

  - その回の受付中にまとめた人は、名簿に mergeCk・mergeTeam・mergeKeep を残し、元に戻すと受付・チーム・引き継いだ印も戻す
  - 名前を戻すのは nameChk.v がいまの名前と同じときだけ。記録の移動は mv（移した回数）を1ずつ増やす。版12のまとめ（mergeId なし）は unmergeOf を空で戻せる
  - 参加者画面の中身は、送信中の変更・失敗をやり直し、ほかの端末の古い中身で上書きされたら書き直す（1分20回まで）。失敗・大きすぎ（900KB）は運営画面の状況に出す
  - 運営画面に、古い版のままの端末（各端末の報告の ver）を出す
  - 参加者画面：URLの fake 指定をやめた。届いたデータは型をそろえてから出す。同じ日の2件は良い方の順位で数える
  - 抽選の優先順（丸岡さん確認）：目印 ＞ 早帰りで1人残りを作らない ＞ 経験豊富の人数 ＞ 実績上位 ＞ 初心者 ＞ 早帰りを散らす ＞ 評価の合計。全員早帰りのチームは避けない
  - 実績上位：前回の覇王戦より後の大会で、優勝2点・3位以内1点。多い順にチーム数と同じ人数（同点は含める）。運営画面だけに「実績」と出す
